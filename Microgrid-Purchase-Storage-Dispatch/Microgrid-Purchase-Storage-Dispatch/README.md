# 微网购电与储能协同调度优化

面向含光伏和储能的微电网运行场景，构建从日内经济调度、预测偏差应对，到多时点预测信息利用和动态电价响应的完整分析流程。项目以混合整数线性规划和滚动优化为核心，在10分钟调度粒度下协同考虑购电、储能状态、预测信息、实时修正和结算规则。

## 项目概览

微电网的购电与储能决策需要同时处理能源成本、储能物理约束、光伏波动、预测误差和价格变化。本项目把这些问题整合为一套协同调度框架：先建立储能经济运行基线，再扩展至日前计划和实时修正，继而分析新增预测信息与动态价格如何改变调度策略。

## 核心工作

### 储能运行与经济调度

建立含充放电互斥、SOC上下限、充放电效率和功率限制的混合整数线性规划模型，联合优化微网购电和储能充放电；分析储能对峰谷转移、光伏消纳及购电成本的影响，并开展关键参数敏感性分析。

### 预测偏差下的日前与实时协同

构建基于历史信息的日前计划与10分钟实时滚动修正流程，将预测偏差、备用策略和储能状态更新纳入调度，分析策略在全年连续运行场景下对计划成本、紧急购电和SOC轨迹的影响。

### 多时点预测信息价值评估

围绕不同光伏预报更新时间构造滚动决策策略，比较单次日前预测与日内更新的运行结果；结合已执行时段锁定和实时SOC状态，评估新增预测信息对合同调整、储能调度和系统费用的影响。

### 动态电价响应与储能策略

将固定价格情景扩展至动态电价，比较不同价格信息条件和价格预测策略下的购电与储能响应；通过一致的实际价格结算口径分析价格信息、预测误差和合同调整的作用。

## 方法与技术

- 混合整数线性规划（MILP）与 SciPy `milp` 求解
- 稀疏矩阵形式的线性约束建模
- 日前计划、滚动时域优化与实时补救调度
- 预测误差校正、风险备用和敏感性/对照分析
- SOC连续状态跟踪、物理约束审计与结果诊断
- Python、NumPy、SciPy、OpenPyXL、Matplotlib

## 项目结构

```text
.
├── storage_dispatch.py          # 储能运行与经济调度
├── rolling_dispatch.py          # 日前计划与实时滚动调度
├── forecast_value.py            # 多时点预测信息价值评估
├── dynamic_price_dispatch.py    # 动态电价响应与调度
├── data/                        # 原始题目数据及官方结果模板
├── 储能调度结果/                # 成本、SOC与敏感性分析
├── 滚动调度结果/                # 日前与实时修正结果
├── 预测信息评估结果/            # 多时点预测策略结果
├── 动态电价结果/                # 价格响应与合同分析
├── 项目论文.pdf
├── requirements.txt
└── README.md
```

结果目录按储能调度、实时滚动、预测信息评估和动态电价响应分类，代码文件也按项目功能命名，便于从业务问题和技术模块理解整体实现。

## 环境与运行

建议使用 Python 3.10 或更新版本：

```bash
python -m pip install -r requirements.txt
```

各模块从项目根目录的 `data/` 读取输入。常用运行示例：

```bash
# 储能日内经济调度
python storage_dispatch.py

# 日前计划与实时滚动调度
python rolling_dispatch.py --mode main

# 预测信息价值：审计输入后运行短期演示
python forecast_value.py --mode audit
python forecast_value.py --mode demo --start-date 2025-03-20 --days 7 --scenarios core

# 动态电价模块：审计输入后运行短期演示
python dynamic_price_dispatch.py --mode audit
python dynamic_price_dispatch.py --mode demo --branch q42 --price-info P2
```

问题2至问题4也支持全年或多情景运行，计算量高于审计和短期演示。运行参数可通过 `python <模块文件名> --help` 查看。运行脚本会在项目目录生成或更新结果文件。

## 输入与结果

`data/` 包含附件1至附件4和附件5中的官方结果模板；`result1.xlsx` 放在 `data/附件5/`，脚本会从该位置读取。项目当前附有四个模块已生成的结果表、CSV汇总、诊断图和 SVG 可视化，可直接浏览。
